--- Certificate Email Bug Fix ---
File:    backend/src/services/emailService.js
Problem: certificateService.js stores pdfPath as "/certificates/FILENAME.pdf" (URL-style).
         emailService.js called fs.existsSync(pdfPath) on this path.
         On Windows with cwd=d:\educity\backend, this resolved to C:\certificates\...
         which does not exist -> email failed silently.
Fix:     Added path import and resolved to absolute path before file operations:
           const absolutePdfPath = pdfPath.startsWith('/')
             ? path.join(process.cwd(), pdfPath)
             : pdfPath;
         All fs.existsSync / fs.statSync / fs.readFileSync now use absolutePdfPath.

--- Enrollment Approval Gap (Known Issue) ---

Recommendation: Add PATCH /admin/enrollments/:id/approve endpoint.
